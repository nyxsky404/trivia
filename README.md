# React Quiz App

A modern, interactive quiz application built with React that allows users to test their knowledge across various topics.

## Features

- Interactive quiz interface
- Multiple choice questions
- Score tracking
- Responsive design
- Instant feedback on answers

## Technologies Used

- React.js
- JavaScript (ES6+)
- CSS3
- HTML5

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/nyxsky404/trivia/
   ```

2. Navigate to the project directory

   ```bash
   cd quiz-app-react
   ```

3. Install dependencies

   ```bash
   npm install
   ```

4. Start the development server

   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) to view it in your browser

## Usage

1. Start the quiz by clicking the 'Start' button
2. Select your answer from the multiple choice options
3. Submit your answer to see if it's correct
4. Continue through all questions to get your final score

## Development

- Run development server: `npm start`
- Build for production: `npm run build`
- Run tests: `npm test`
